= O que há de novo no SnapCenter Plug-in for VMware vSphere 6.2.1
:allow-uri-read: 


[role="lead"]
O SnapCenter Plug-in for VMware vSphere 6.2.1 é uma versão de manutenção. Ele atualiza o software de terceiro fornecido com o appliance e inclui correções para problemas encontrados desde a versão 6.2 do SnapCenter Plug-in for VMware vSphere.



[[updated-components]]
== Componentes atualizados

|===
| Componente | O SnapCenter Plug-in for VMware vSphere 6.2.1 


| Tempo de execução Java | OpenJDK 21.0.12 


| Tempo de execução .NET | .NET 10.0.11 


| Sistema operacional do appliance | Debian 13 
|===


[[fixed-issues]]
== Problemas corrigidos

É uma boa prática revisar os problemas conhecidos corrigidos em uma versão antes de atualizar para ela.

|===
| ID do bug | Descrição 


| VMDP-7072 | O ONTAP gerenciado na nuvem no Oracle Cloud pode ser adicionado como um sistema de storage. 


| VMDP-7052 | Restaurar uma VM em um local diferente mantém a política de storage da VM, portanto a restauração não é mais rejeitada para VMs que usam uma política não padrão. 


| VMDP-7027 | Os pacotes de logs de suporte incluem a lista de sistemas de storage configurados. 


| VMDP-6987 | A conexão ou restauração de um disco virtual não falha mais quando vCenter relata brevemente o datastore como indisponível. 


| VMDP-6965 | A página de agendamentos não apresenta mais problemas de carregamento quando um registro de agendamento está incompleto. 


| VMDP-6952 | Quando um usuário não tem permissão para excluir um grupo de recursos, a mensagem de permissão é exibida. 


| VMDP-6939 | O console de manutenção não informa mais que o VMware Tools está ausente. 


| VMDP-6935 | Navegar em um backup para restaurar arquivos individuais não falha mais. 


| VMDP-6933 | A implantação de um novo dispositivo não falhará mais durante a configuração inicial. 


| VMDP-6931 | A limpeza de backups secundários não fica mais aguardando horas em um volume que não consegue acessar. O processamento dos outros volumes continua. 


| VMDP-6817 | Renomear um volume de origem do ONTAP não deixa mais os backups secundários presos ao nome antigo, nem exibe entradas que não são mais válidas. 
|===
