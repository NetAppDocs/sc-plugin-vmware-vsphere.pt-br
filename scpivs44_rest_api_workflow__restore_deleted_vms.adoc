= Fluxo de trabalho da API REST para restaurar VMs excluídas usando o SCV
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Para executar operações de restauração de backups de VM usando o plug-in do SnapCenter para APIs REST do VMware vSphere, você deve seguir a sequência prescrita de chamadas de API REST.

Para cada API REST, adicione `\https://<server>:<port>` na frente da API REST para formar um endpoint completo.

|===
| Passo | API REST | Comentários 


| 1 | Vá para `\http://<vCenter-IP>/mob` | Encontre o *moref* do datastore a partir da URL do VMware Managed Objects. Anote o moref do datastore no qual a VM excluída residia. 


| 2 | `/4.1/datastores/{moref}/backups` | `Get Datastore Backups`Recupera uma lista de backups para o datastore especificado. Passe o *moref* da etapa 1. Observe o *backupId* do backup que você deseja restaurar. 


| 3 | `/4.1/backups/{backupId}` | `Get Backup Details` recupera os detalhes do backup especificado. Passe o *backupId* da etapa 2. Na lista de entidades, encontre o *entityName* que corresponde à VM excluída e anote o *UUID*. 


| 4 | `/4.1/vm/backups/{backupId}/snapshotlocations` | `Get snapshot locations`Recupera a localização do snapshot para o backup especificado. Passe o *backupId* da etapa 2. Anote as informações de *snapshotLocationsList*. 


| 5 | `/4.1/datastores/{moref}/availableEsxHosts` | `Get available ESX Hosts` recupera as informações do host onde o backup está armazenado. Passe o *moref* da etapa 1. Observe as informações de *availableEsxHostsList*. 


| 6 | `/4.1/vm/{uuid}/backups/{backupId}/restoreVm` | `Restore a VM from a backup` restaura o backup especificado. Passe o *UUID* da etapa 3. Passe o *backupId* da etapa 2. No atributo *restoreLocations*, passe as informações do *snapshotLocationsList* na etapa 4; no atributo *esxHost*, passe as informações do *availableEsxHostsList* na etapa 5. Se o backup de VM for um backup parcial, defina o parâmetro  `restartVM` como *false*. *Observação:* você não pode restaurar uma VM que seja um template. 
|===
