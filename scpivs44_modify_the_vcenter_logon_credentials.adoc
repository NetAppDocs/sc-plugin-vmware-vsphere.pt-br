= Atualize as credenciais do vCenter configuradas no SCV
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Use esta tarefa para atualizar as credenciais de logon do vCenter configuradas no SnapCenter Plug-in for VMware vSphere. O SCV usa essas credenciais para acessar o vCenter. Quando a credencial do vCenter for alterada, atualize-a no SCV para que o vCenter permaneça registrado no SCV. Para backups de vVol, cancele o registro das ONTAP tools for VMware vSphere e, em seguida, registre novamente as ONTAP tools com a nova senha para que os backups continuem funcionando.

.Antes de começar
Você deve saber o endereço IP e as credenciais de logon para a interface de usuário de gerenciamento do SnapCenter Plug-in for VMware vSphere .  Você também deve anotar o token MFA gerado pelo console de manutenção.

* O endereço IP foi exibido quando o plug-in do SnapCenter para VMware vSphere foi implantado.
* Use as credenciais de login fornecidas durante a implantação do plug-in do SnapCenter para VMware vSphere ou conforme modificado posteriormente.
* Gere um token MFA de 6 dígitos usando as opções de configuração do sistema do console de manutenção.


.Passos
. Efetue login na interface de usuário de gerenciamento do SnapCenter Plug-in for VMware vSphere .
+
Utilize o formato `\https://<appliance-IP-address>:8080`

. No painel de navegação esquerdo, selecione *Configuração*.
+
image:scpivs44_image30.png["SnapCenter Plug-in for VMware vSphere"]

. Na página *Configuration*, na seção *vCenter*, selecione *Edit*.
. Introduza a nova palavra-passe e, em seguida, selecione *Guardar*.
+
Não modifique o número da porta.



.Depois de terminar
Após salvar as novas credenciais, verifique se o SCV ainda está conectado a vCenter.

* Na interface de usuário de gerenciamento do SnapCenter Plug-in for VMware vSphere, abra *Dashboard* e verifique se o SCV está conectado ao vCenter e habilitado.
* No vSphere Client, verifique se o menu *SnapCenter Plug-in for VMware vSphere* está sendo exibido e se as páginas do plug-in carregam.
* Opcional: Abra um grupo de recursos ou execute um backup sob demanda para verificar se as operações do vCenter estão funcionando.


Se o SCV não estiver conectado após a alteração da credencial, reinicie o serviço do cliente vSphere VMware. Se o SCV ainda não estiver conectado, acesse link:scpivs44_post_deployment_required_operations_and_issues.html["Operações e problemas pós-implantação necessários para o SCV"].
